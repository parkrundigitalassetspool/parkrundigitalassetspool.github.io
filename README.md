# parkrun digital assets pool

Static GitHub Pages profile website for `parkrundigitalassetspool`.

## Publish on GitHub Pages

1. Create a repository named `parkrundigitalassetspool.github.io` under the GitHub username `parkrundigitalassetspool`.
2. Upload the contents of this folder and push to the `main` branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.

The page is plain HTML/CSS/JavaScript, so it needs no build step. The source PDF is included as `parkrun Digital assets pool.pdf` and linked from the page.

The personal GitHub Pages URL will be: `https://parkrundigitalassetspool.github.io/`
